HSN-Shaders Lite 26.3.6
Iris / OptiFine pack for Minecraft 26.3 (and compatible OptiFine builds). Built to stay light.

Profiles
- Potato: no shadows, no bloom
- Low: hard shadows, small bloom
- Medium: soft shadows, fog
- High: same look as Medium, longer shadow distance

Sun and moon get a soft color glow so they are not dim.
Post processing (bloom, vignette, sharpen, color) can be turned off in the shader menu.
Experimental SSAO and god rays are available in the Experimental menu — both off by default.
Vines stay still. Grass and leaves can still wave.

Install
Drop the zip into shaderpacks. Do not unzip.
